**«Веб-платформа для математических вычислений и анализа данных»**

---

**Что делает пользователь:**
1. Заходит на сайт.
2. Выбирает тип задачи (например, "Решение квадратного уравнения", "Статистика по данным", "Работа с матрицами", "Построение графика функции").
3. Вводит данные через форму.
4. Получает результат + график.
5. История всех вычислений сохраняется в личном кабинете.
